# Changelog

All notable changes to facut will be documented in this file.

## 0.1.0 — 2026-07-28

### Added

- Cross-platform Typer CLI with stable JSON responses and exit codes.
- Non-destructive project files, schema validation, atomic saves, and revisions.
- Content-addressed media import, FFprobe inspection, thumbnails, proxies, and waveforms.
- Frame-aware timeline editing, trimming, splitting, movement, speed changes, and ripple deletion.
- Plugin registries for transitions and video effects.
- Real FFmpeg dissolve transitions, low-resolution range previews, and H.264/AAC rendering.
- Atomic JSON command batches, dry runs, snapshots, undo, and redo.
- Windows single-file release with embedded FFmpeg/FFprobe 8.1.2.
- Cross-platform tests and a verified 4K rendering acceptance flow.

### Known limitations

- The 0.1 renderer accepts one enabled video/image track.
- Independent background-music tracks, subtitle burning, animated text, and AI content analysis are planned for later releases.
